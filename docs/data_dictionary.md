# AEGIS data dictionary

All data is **synthetic** (generated by `producers/`); every raw record carries
`"synthetic": true`. Timestamps in canonical tables are UTC. Ranges are
inclusive and defined in `aegis/canonical.py` (`RANGES`).

## 1. Raw source formats (Kafka values / JSONL lines)

### weather-events — `wx-metric-1` (WXM-* stations)

| Field | Type | Unit / format | Required | Notes |
|---|---|---|---|---|
| event_id | string | `WX-<hex>` | yes | event identity / dedup key |
| source_type | string | `weather` | yes | must match the topic |
| source_id | string | station id | yes | |
| schema_version | string | `wx-metric-1` | yes | |
| event_time | string | ISO-8601 with `+05:30` | yes | |
| lat, lon | number | WGS84 degrees | yes | |
| temperature_c | number | °C | no | −20…55 |
| humidity_pct | number | % | no | 0…100 |
| rainfall_mm_hr | number | mm/hr | yes | 0…300 |
| condition | string | free text (`Heavy Rain`, `drizzle`, …) | no | normalised |

### weather-events — `wx-imperial-2` (AWS-* stations)

| Field | Type | Unit / format | Required | Maps to |
|---|---|---|---|---|
| obs_id | string | | yes | event_id |
| station | string | | yes | source_id |
| ts_ms | integer | epoch milliseconds | yes | event_time |
| location.latitude / location.longitude | number | degrees | yes | lat / lon |
| temp_f | number | °F | no | temperature_c = (F − 32)·5/9 |
| rh_pct | number | % | no | humidity_pct |
| precip_in_hr | number | inches/hr | yes | rainfall_mm_hr = in·25.4 |
| sky | string | METAR-like code (`+RA`, `TSRA`, `CLR`) | no | condition |

### water-level-events — `wl-1`

| Field | Type | Unit / format | Required | Notes |
|---|---|---|---|---|
| event_id, source_id, schema_version, source_type | string | | yes | |

### traffic-events — `tr-1`

| Field | Type | Unit / format | Required | Notes |

## 2. Canonical (silver) columns

Common to every silver table (`lake/silver/<domain>`, `lake/silver_stream/<domain>`):

| Column | Type | Meaning |
|---|---|---|
| event_id | string | unique per table after de-duplication |
| source_type, source_id, schema_version | string | provenance |
| event_time | timestamp (UTC) | when the observation/report happened |
| event_date | date | partition column (UTC date of event_time) |
| lat, lon | double | NULL when absent; invalid coordinates are rejected |
| zone_id | string | analysis grid cell `Z-R<row>-C<col>`; NULL without coordinates |
| is_synthetic | boolean | always true here |
| dq_flags | array<string> | non-fatal quality flags (see §4) |
| origin | string | `kafka` or `file:<name>` |
| ingest_time | timestamp | Kafka record timestamp (NULL for files) |
| processing_time | timestamp | when Spark processed the record |

## 3. Rejection reasons (quarantine)

`reasons` holds detailed codes, `reason_codes` the prefixes.

| Code | Trigger |
|---|---|
| malformed_json | payload is not a parseable JSON object |
| topic_source_mismatch / unknown_source_type | `source_type` not valid for the topic |
| unknown_schema_version | version not in `aegis/canonical.SCHEMA_VERSIONS` |
| missing_required:<field> | required field absent |
| invalid_type:<field> | present but not castable (e.g. `"rainfall_mm_hr": "heavy"`) |
| invalid_timestamp | time present but unparseable |
| future_timestamp | more than 5 minutes after processing time |
| invalid_coordinates | lat ∉ [−90, 90] or lon ∉ [−180, 180] |
| outside_study_region | valid coordinates outside the bounding box |
| out_of_range:<field> | canonical value outside `RANGES` |
| invalid_unit | water-level unit not m/cm/mm/ft |

## 4. Data-quality flags (valid records)

| Flag | Meaning | Effect |
|---|---|---|
| late_arrival | ingest − event time > watermark (10 min) | dropped from live windows by the watermark; kept in bronze and batch |
| sensor_fault | gauge reports fault | excluded from risk aggregation |
| sensor_degraded | gauge degraded/low battery | kept |
| missing_coordinates | report without lat/lon | no zone; excluded from spatial analytics |
| unknown_category / unknown_condition / unknown_status | text not in the vocabulary | mapped to `other` / `unknown` |
| missing_optional | optional measurement absent | value stays NULL (never invented) |
